# سایت ایجنت‌یار (Agentyar)

سایت استاتیک فارسی (RTL) — بدون build، بدون فریم‌ورک، بدون وابستگی npm.
کافی است فایل‌ها را روی GitHub بگذارید و GitHub Pages را روشن کنید.

---

## ۱) ساختار فایل‌ها

```
agentyar/
├── index.html            صفحه اصلی (هیرو، خدمات، درباره، وبلاگ، سوالات، فرم، تماس)
├── business.html         ایجنت‌یار بیزنس (B2B) + فرم دمو
├── blog.html             لیست مقالات + جست‌وجو و فیلتر دسته‌بندی
├── article.html          قالب صفحه‌ی یک مقاله (برای مقالات بعدی کپی بگیرید)
├── 404.html              صفحه خطا
├── site.webmanifest      تنظیمات PWA / آیکون موبایل
├── robots.txt            راهنمای موتورهای جست‌وجو
├── sitemap.xml           نقشه سایت
├── .nojekyll             لازم برای GitHub Pages
└── assets/
    ├── css/style.css     تمام استایل‌ها (با کامنت فارسی، بخش‌بندی‌شده)
    ├── js/main.js        تمام اسکریپت‌ها (بالای فایل یک بلاک CONFIG هست)
    ├── img/              لوگو، فاوآیکون، تصاویر کاور، تصویر اشتراک‌گذاری
    └── fonts/            (خالی — فقط اگر خواستید فونت را self-host کنید)
```

## ۲) آپلود روی GitHub Pages

### روش A — دامنه‌ی رایگان github.io

1. یک ریپوی جدید بسازید (مثلاً `agentyar-site`)، Public.
2. همه‌ی فایل‌های داخل این پوشه را **مستقیم در ریشه‌ی ریپو** بریزید (نه داخل یک پوشه‌ی دیگر).
3. در ریپو: `Settings` → `Pages` → بخش **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` و فولدر `/ (root)` → Save
4. یکی‌دو دقیقه بعد سایت روی `https://<username>.github.io/agentyar-site/` بالا می‌آید.

با خط فرمان:

```bash
cd agentyar
git init
git add .
git commit -m "Agentyar website"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

### روش B — دامنه‌ی خودتان (چیزی که خریده‌اید)

1. یک فایل به اسم `CNAME` (بدون پسوند) در ریشه‌ی ریپو بسازید و فقط دامنه را داخلش بنویسید:
   ```
   agentyar.com
   ```
2. در پنل DNS دامنه، رکوردها را اضافه کنید:

   | نوع | نام | مقدار |
   |---|---|---|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | `<username>.github.io` |

3. در `Settings → Pages` دامنه را در Custom domain وارد کنید و **Enforce HTTPS** را تیک بزنید.

> اگر دامنه `.ir` است، بعضی رجیسترارهای ایرانی رکورد A روی `@` را محدود می‌کنند؛ در آن صورت از `www` با CNAME استفاده کنید و ریدایرکت `@` را از خود پنل رجیسترار بزنید.

## ۳) چک‌لیست چیزهایی که **باید** قبل از انتشار عوض کنید

| مورد | کجا | وضعیت |
|---|---|---|
| شماره واتساپ | `main.js` → `CONFIG.whatsapp` | ✅ `989350886064` |
| ایمیل | `index.html`, `main.js`, فوتر همه‌ی صفحات | ✅ `Jafariyounes8@gmail.com` |
| شماره تلفن کارت «تماس تلفنی» | `index.html` بخش تماس | ✅ همان موبایل — اگر تماس تلفنی نمی‌خواهی، کل آن کارت را پاک کن |
| دامنه | همه‌ی HTMLها + `robots.txt` + `sitemap.xml` + `CNAME` | ✅ `agentyar.com` |
| اینستاگرام | همه‌ی صفحات (فوتر + بخش تماس) | ✅ `@Agentyar_com` |
| لینکدین / تلگرام / یوتیوب | فوتر همه‌ی صفحات | ⬜ هنوز `href="#"` است — اگر نداری، آیکون‌ها را پاک کن |
| اعداد آمار | `index.html` و `business.html` | ⚠️ پایین را بخوانید |

> فایل `CNAME` با محتوای `agentyar.com` آماده در ریشه هست. فقط رکوردهای DNS بخش ۲ را بزن.

جایگزینی سریع دامنه در همه‌ی فایل‌ها:

```bash
grep -rl "agentyar.com" . | xargs sed -i 's/agentyar\.com/YOURDOMAIN.com/g'
```

### ⚠️ درباره‌ی اعداد آمار

اعداد `۱۰٬۰۰۰+ کاربر فعال`، `۲۰۰+ کسب‌وکار همکار`، `۹۸٪ رضایت` (و در صفحه بیزنس `۵۰+ سازمان`، `۹۵٪ رضایت`، `۳۰٪+ بهره‌وری`) از خود موکاپ آمده‌اند و **عدد واقعی نیستند**.
اگر آمار واقعی ندارید، این بلاک‌ها را یا با عدد واقعی جایگزین کنید یا کلاً حذف کنید — ادعای عددی نادرست روی صفحه‌ی اول، اولین چیزی است که یک مشتری B2B می‌تواند راستی‌آزمایی کند.

برای حذف کامل بلاک آمار، در `index.html` و `business.html` کل `<div class="stats"> … </div>` را پاک کنید.

جایگزین‌های بی‌ریسک برای همان فضا:
- «رزرو نوبت، پاسخ دایرکت، یادآوری — خودکار»
- «راه‌اندازی در کمتر از ۷ روز»
- «بدون نیاز به نصب یا آموزش»

## ۴) فرم‌ها چطور کار می‌کنند

بالای `main.js` یک بلاک تنظیمات هست:

```js
var CONFIG = {
  whatsapp: '989350886064',            // شماره واتساپ، با کد کشور، بدون + و بدون صفر
  formEndpoint: '',                    // خالی = انتقال به واتساپ
  email: 'Jafariyounes8@gmail.com'
};
```

سه حالت:

1. **پیش‌فرض (بدون سرور):** کاربر فرم را پر می‌کند → با یک پیام آماده به واتساپ شما منتقل می‌شود. برای شروع کاملاً کافی است.
2. **با سرویس فرم:** در [Formspree](https://formspree.io) یا [Getform](https://getform.io) یک فرم بسازید و آدرس آن را در `formEndpoint` بگذارید. اطلاعات به ایمیل شما می‌آید.
3. **API خودتان:** هر endpoint ی که JSON با متد POST بپذیرد.

> GitHub Pages سرور ندارد، پس فرم بدون یکی از این سه راه هیچ جایی ذخیره نمی‌شود.

## ۵) اضافه کردن مقاله‌ی جدید

1. از `article.html` یک کپی بگیرید: مثلاً `article-ai-tools.html`.
2. عنوان، متن، تاریخ و `og:` ها را عوض کنید.
3. در `blog.html` یک کارت جدید اضافه کنید (از روی کارت‌های موجود کپی بگیرید):

```html
<a class="post" href="article-ai-tools.html" data-category="ai" data-tags="کلمات کلیدی برای جست‌وجو">
  <div class="post__media">
    <img src="cover-1.svg" alt="" loading="lazy" width="800" height="500">
    <span class="post__badge">راهنما</span>
  </div>
  <div class="post__body">
    <h3>عنوان مقاله</h3>
    <div class="post__meta"><span>تاریخ</span><span>۵ دقیقه مطالعه</span></div>
  </div>
</a>
```

`data-category` باید یکی از این‌ها باشد: `ai` · `product` · `success` · `business`
(اگر دسته‌ی جدیدی خواستید، یک `chip-btn` با `data-filter` متناظر در `blog.html` اضافه کنید.)

تصاویر کاور فعلی، گرافیک‌های SVG ساخته‌شده هستند. هر وقت عکس واقعی داشتید، در `` بگذارید و `src` را عوض کنید (نسبت ۱۶:۱۰، حداقل ۸۰۰×۵۰۰).

## ۶) فونت

الان وزیرمتن از Google Fonts لود می‌شود (در `<head>` هر صفحه). اگر خواستید کاملاً مستقل از اینترنت بیرونی باشد:

1. فایل‌های `woff2` وزیرمتن را از [اینجا](https://github.com/rastikerdar/vazirmatn/releases) دانلود کنید و در کنار بقیه فایل‌ها بگذارید.
2. تگ‌های `fonts.googleapis.com` و `fonts.gstatic.com` را از `<head>` همه‌ی صفحات حذف کنید.
3. در بالای `style.css` بلاک `@font-face` را از حالت کامنت خارج کنید.

مزیت: سرعت بالاتر برای کاربر ایرانی و بی‌نیازی از سرویس بیرونی.

## ۷) رنگ‌ها و تم

همه‌ی رنگ‌ها در `:root` بالای `style.css` تعریف شده‌اند. برای تغییر کل هویت رنگی سایت فقط این چند خط کافی است:

```css
--brand:        #21e06b;   /* سبز اصلی */
--brand-bright: #4dff92;   /* سبز روشن (گرادیان) */
--brand-mid:    #16b757;
--brand-deep:   #0c7a3a;
--bg-base:      #050806;   /* پس‌زمینه */
```

## ۸) چیزهایی که رعایت شده

- RTL کامل با ویژگی‌های منطقی CSS (`inset-inline`, `margin-inline`)
- ریسپانسیو از ۳۲۰px تا دسکتاپ
- بدون جاوااسکریپت هم کل محتوا دیده می‌شود (انیمیشن‌ها فقط لایه‌ی اضافه‌اند)
- `prefers-reduced-motion` برای کاربرانی که انیمیشن اذیتشان می‌کند
- متاتگ‌های SEO و Open Graph + داده‌ی ساخت‌یافته (JSON-LD)
- `skip-link`، `aria-label` و فوکوس قابل‌مشاهده برای دسترسی‌پذیری
- بدون هیچ کتابخانه‌ی خارجی (به‌جز فونت) — سرعت لود بالا

# Agentyar website

Independent static version of the Agentyar website, prepared for GitHub Pages and `agentyar.com`.

## Publish
1. Push these files to the `main` branch of a GitHub repository.
2. In Repository Settings → Pages, choose **GitHub Actions** as the source.
3. In Settings → Pages → Custom domain, set `agentyar.com`.
4. Configure DNS at the domain provider.
